# Ducks on Demand

A small, static, **fictional** rubber duck store. It is a public test page for website analysis tools (SEO and accessibility checkers such as RankAbove).

Live site: https://fdusi0027.github.io/ducks-on-demand/

## Disclaimer

Ducks on Demand is a fictional demo store made for testing website tools. Nothing is for sale. Product photos are used under open licenses. Fictional demo site. Not affiliated with any real business of this name.

There is no cart, checkout, form, script, email address or phone number on the site.

## Intentional flaws

Two small flaws are left in on purpose, so an analysis tool has something to find. They are not mentioned on the site.

1. `about.html` has a very short meta description (about 48 characters).
2. In `ducks.html`, the "Pond Pal" catalogue image (`images/glass-bowl.jpg`) has no `alt` attribute.

Everything else is meant to be correct.
